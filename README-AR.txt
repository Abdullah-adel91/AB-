المحاكاة – نسخة اختبار V4

المحتويات:
- index.html: الموقع
- manifest.webmanifest وأيقونات PNG: تثبيت الموقع كتطبيق على الجوال
- sw.js: تخزين ملفات الواجهة لفتحها عند ضعف/انقطاع الاتصال بعد أول زيارة

النشر على GitHub Pages:
1) أنشئ مستودع GitHub جديداً وارفع الملفات الأربعة الموجودة في هذا المجلد إلى الجذر.
2) من Settings ثم Pages، اختر Deploy from a branch، ثم main و / (root)، واحفظ.
3) افتح رابط GitHub Pages الناتج من Safari على iPhone أو Chrome على Galaxy.
4) على iPhone: مشاركة ثم Add to Home Screen. على Galaxy: قائمة Chrome ثم Install app / Add to Home screen.

مهم:
- يجب استخدام رابط HTTPS؛ فتح ملف HTML مباشرة من المعاينة أو من تطبيق الملفات قد يمنع التخزين المحلي وتشغيل بعض وظائف المتصفح.
- هذه نسخة واجهة محلية تجريبية: تحفظ بيانات هذا المتصفح على هذا الجهاز فقط. لم يتم بعد ربط Supabase أو تسجيل دخول المستخدمين أو مشاركة البيانات بين الأجهزة.
- تصدير Excel مؤجل كما اتفقنا.
