المحاكاة – V7

ما تم تعديله:
1. استيراد قاعدة الموظفين من ملف Excel بصيغة XLSX مباشرة.
2. يقرأ الموقع ورقة Ops Active فقط، ولا يقرأ ورقة Agent.
3. يعتمد الأعمدة المحددة: C = اسم الموظف بالعربي، D = User ID الكامل، F = Iqama ID.
4. عند كتابة R117 في صفحة التقييم، يحوّله إلى RCC933-117 ويبحث في User ID، ثم يعبّئ الاسم والهوية تلقائياً.
5. إذا لم يجد اليوزر، يظهر تنبيه واضح ويسمح بالإدخال اليدوي.
6. الاستيراد يتم محلياً داخل المتصفح. ملف Excel لا يُرسل إلى خادم ولا يُرفع تلقائياً إلى GitHub.
7. تصحيح تصدير Excel: عشرة أعمدة بالترتيب المتفق عليه، مع حالة الالتزام في العمود E والوقت الفعلي للتقييم في J.
8. الإبقاء على مفاتيح التخزين السابقة حتى تنتقل بيانات V6 المحلية إلى V7 على الجهاز والمتصفح نفسيهما.
9. تحديث ملفات التطبيق القابل للتثبيت والعمل دون اتصال بعد تحميل الموقع أول مرة.

أعمدة ملف Excel المصدر:
- ورقة العمل: Ops Active
- C: Agent Name Arb (اسم الموظف بالعربي)
- D: User ID (اليوزر الكامل، مثل RCC933-117)
- F: Iqama ID (رقم الهوية)

المخرج النهائي Excel:
A الرقم التسلسلي
B التاريخ
C اسم الموظف
D رقم الهوية
E حالة الالتزام
F نص السؤال
G ملاحظة الجودة
H القسم
I اسم مراقب الجودة
J الوقت

طريقة التحديث على GitHub Pages:
1. فك ضغط almohakaa-v7-github-pages.zip.
2. افتح مستودع almohakaa الحالي في GitHub.
3. اختر Add file ثم Upload files.
4. ارفع كل محتويات المجلد إلى جذر المستودع واستبدل الملفات القديمة ذات الأسماء نفسها.
5. اضغط Commit changes وانتظر اكتمال النشر.
6. افتح رابط الموقع وحدّث الصفحة. إذا كان التطبيق مثبتاً، أغلقه وافتحه بعد النشر.

طريقة إدخال قاعدة الموظفين:
1. افتح تبويب قاعدة الموظفين.
2. اختر ملف قاعدة الموظفين بصيغة XLSX.
3. سيقرأ الموقع ورقة Ops Active والأعمدة C وD وF فقط.
4. وافق على استبدال قاعدة الموظفين المحلية عند ظهور رسالة التأكيد.
5. اكتب R117 في صفحة التقييم الميداني، وتحقق من ظهور الاسم والهوية.

تنبيه الخصوصية والحفظ:
- لا ترفع ملف قاعدة الموظفين الحقيقي أو أي بيانات هوية إلى مستودع GitHub، خصوصاً إذا كان المستودع عاماً.
- الاستيراد يُقرأ داخل المتصفح ويُحفظ محلياً على الجهاز نفسه. لا توجد مزامنة بين الأجهزة أو حسابات المراقبين في هذه النسخة.
- كل جهاز يحتاج إلى استيراد ملف قاعدة الموظفين بنفسه. تقييمات كل جهاز تبقى في تخزين ذلك الجهاز والمتصفح.
- مسح بيانات Safari/Chrome أو تغيير الجهاز قد يؤدي إلى فقد البيانات المحلية. احتفظ بنسخة احتياطية آمنة.
- اختبر أولاً بملف تجريبي وبهوية وهمية قبل إدخال بيانات العمل الحقيقية.
- صيغة المصدر المدعومة هنا XLSX الحديثة، وليست XLS القديمة.
